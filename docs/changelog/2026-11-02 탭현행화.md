## JM님께 확인받을 것
- **Add 구간(코스피 7,000~7,200 + 외국인 순매수 → 한국 20%→28%)**은 현재가보다 약 22% 위라 사실상 "회복 확인 뒤 재진입" 규칙이 됐다. 시나리오 재설정으로 불 구간의 아래 경계(7,000)와 맞아떨어지긴 하지만, 하락장 매수 구간으로 쓰려면 다시 정해야 한다(예: 베이스 구간 아래쪽 5,500 안팎).
- **삼성전자 분할 기준**(현재가 1/3 · 7,000~7,200 1/3 · 6,500 접근 시 1/3)도 같은 이유로 현재가보다 모두 위다. 지금은 Stop-Loss가 신규 매수를 막고 있어 실행에는 영향이 없다.
- **시나리오 확률**은 50/30/20 그대로 뒀다. 11/3 중간선거·11/6 고용·11/10 CPI·12/9 FOMC 이후에 다시 볼 만하다.
