## 발견한 문제와 조치
- **카드 ↔ 서술 불일치(핵심)**: 에디션이 Action보다 먼저 끝나 "WTI 확정 종가 미확보 — 수집 시점 약 $94"라 썼는데 Action이 확정 종가 $96.15(+1.11%)·전날 $95.09를 넣었다. 같은 문제가 SKHY(종가 미확보 → $146.11, −0.98%), VIX(17.6 → 16.5), 공포탐욕(29.7 → 32), 원/달러 문구(약 1,345 → 1,341)에도 있었다. `us_issues`·`stance`·`triggers`의 해당 문구를 확정값으로 교체했다(**`status`는 건드리지 않음** — De-risk는 봉쇄 조건 미확인이라 approaching 유지). 한국 이슈 카드의 종목 종가는 KRX Open API 확정치와 일치해 "(언론 집계)" 표기를 "(KRX 확정)"으로 바꿨다. WTI 카드 해설의 "$95 문턱 근처까지 올라왔다"는 날짜 박힌 표현이라 "문턱을 사이에 두고 오르내리고 있다"로 일반화.
- **경제 캘린더**: `utils/econ_calendar.py`에 재시도(20→40→60초, 시간초과·연결오류·5xx만) 추가, 모의 시험 7경로 통과. `build_briefing.py`는 표가 갱신되지 않을 땐 제목 주차(`econ_cal_week`)도 바꾸지 않도록 수정 — 주 전환일(토) 수집이 실패하면 새 주차 제목 밑에 지난주 표가 남는 라벨-내용 불일치를 막는다.
- **구조적 원인 문서화**: 운영 노트 14 신설(에디션 ↔ Action 시차, 잠정 문구 금지·아침 정렬 절차), 노트 13⑧ 갱신, 경제 캘린더 스키마 절에 재시도·표/제목 동시 유지 명시.
